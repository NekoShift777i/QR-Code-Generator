# Генератор QR-кодов

Консольная программа для создания QR-кодов из текста, ссылок и данных подключения к Wi-Fi. Позволяет настраивать оформление, добавлять логотипы и сохранять готовые изображения в формате PNG.

## Возможности

- QR-коды для текста и ссылок.
- QR-коды для сетей Wi-Fi с защитой WPA2-Personal, WPA3-Personal и без пароля.
- Поддержка скрытых сетей Wi-Fi.
- Добавление логотипа в центр QR-кода.
- Настройка уровня коррекции ошибок, размеров, полей и цветов.
- Готовые наборы настроек «Стандартный» и «Компактный».
- Создание карточки с заголовком и дополнительными сведениями.
- Выбор каталога сохранения и сохранение изображений в PNG.
- Сохранение настроек между запусками.

> Для подключения к Wi-Fi используйте устройство, поддерживающее выбранный тип защиты. Распознавание QR-кода зависит от приложения камеры и операционной системы.

## Запуск готовой программы (Windows)

Запустите `QR-Code-Generator.exe`. Программа работает в окне консоли и не требует отдельной установки Python.

При первом запуске рядом с исполняемым файлом создаётся каталог `data/`, содержащий настройки, пользовательские логотипы и готовые изображения. Для сохранения данных разместите программу в каталоге, доступном для записи (например, в папке пользователя, а не в `Program Files`).

## Запуск из исходного кода

Необходим Python и зависимости из `requirements.txt`.

```powershell
python -m pip install -r requirements.txt
python main.py
```

## Структура проекта

```text
QR-Code-Generator/
├── main.py             # Запуск программы и главное меню
├── config.py           # Настройки и пути к данным
├── qr_generator.py     # Генерация QR-кодов и карточек
├── wifi.py             # Подготовка данных подключения к Wi-Fi
├── logos.py            # Поиск и выбор логотипов
├── menus.py            # Пользовательские меню
├── utils.py            # Общие вспомогательные функции
├── requirements.txt    # Зависимости Python
├── README.md           # Документация
├── icon.ico            # Значок для сборки Windows
├── version_info.txt    # Сведения о версии для Windows
└── data/               # Создаётся автоматически
    ├── config.json     # Пользовательские настройки
    ├── logos/          # Изображения логотипов
    └── output/         # Готовые PNG-файлы
```

Если ранее использовались `config.json` в корне проекта или логотипы в `assets/logos/`, программа переносит их в `data/`, не перезаписывая существующие файлы.

## Сборка исполняемого файла для Windows

Сборка выполняется **на Windows** из корня проекта. Для неё используется PyInstaller (включён в `requirements.txt`).

```powershell
python -m pip install -r requirements.txt
python -m PyInstaller --noconfirm --clean --onefile --console --name "QR-Code-Generator" --icon "icon.ico" --version-file "version_info.txt" main.py
```

Готовый файл появится в `dist/QR-Code-Generator.exe`. При запуске каталог `data/` создаётся рядом с ним. Если распространяете приложение вместе с заранее подготовленными пользовательскими данными, разместите папку `data/` рядом с исполняемым файлом; в противном случае она создастся автоматически.

**Важно:** не используйте `--windowed` или `--noconsole`: программа принимает команды через консоль. Сборка на других операционных системах не создаёт исполняемый файл Windows.
